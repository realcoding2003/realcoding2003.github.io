# 실전코딩 포털 — 디자인 브리프 (Phase 0)

- 작성 2026-11-09 · 기획 정본: 블로그 레포 `.agent/research/2026-11-09_portal-renewal-plan.md`
- 방법: higgsfield-websites 디자인 파이프라인의 Phase 0(브리프)·Phase 1(레퍼런스 보드)만 사용. Higgsfield 사이트 생성·빌드·배포는 하지 않고, 구현은 Astro(우리 스택)에서 한다.
- 이 문서는 구현 계약이다. 이후 단계가 이 내용을 바꾸려면 먼저 이 문서를 고치고 이유를 적는다.

## Design read
개발자이자 메이커인 한 사람의 작업실. 방문자는 개발자·메이커·게이머·의뢰를 고민하는 사람. 정서는 "손으로 만드는 사람의 자신감 + 장난기 있는 정밀함".

## Concept spine
**페이지는 출력 중인 한 판이다.** 스크롤은 Z축 상승, 섹션 하나는 층 하나. 화면 가장자리의 좁은 레일에 현재 층 번호와 Z 높이(고정폭 글꼴)가 스크롤에 맞춰 올라간다. 홈 끝에서 "출력 완료" 상태가 된다. 3D 출력의 층 = 코드의 층 = 게임의 레벨.

## Delivery tier
`cinema` + 3D 한 곳(쇼케이스의 모델 회전 뷰어). 스크롤 영화(히어로), GSAP ScrollTrigger 챕터, Lenis. 사용자 지정 커서 없음. 글 읽기 페이지는 연출 없음.

## Combinatorial pick (모든 보드에 고정)
| 항목 | 선택 |
|---|---|
| Theme paradigm | Deep Dark + 비틀기: 회색 흑색 대신 채도 있는 울트라마린 잉크, 레이어 라인 질감 |
| Background character | 레이어 라인 필드(0.2 mm 간격을 연상시키는 가는 가로 선) + 히어로·영역 섹션은 풀블리드 영상 |
| Typography character | 넓은 statement(Monument 계열 느낌) + 터미널 고정폭 |
| Hero architecture | massive image-first, 글자는 절제 |
| Section system | poster-stacked storytelling(섹션 = 층이 쌓이는 포스터) |
| Signature components | hover-accordion slices(4개 영역) · gapless bento(작업물) · oversized metrics strip(출력 통계) · vertical rhythm lines(층 레일) |
| Narrative spine | tool / precision instrument(프린터·슬라이서) |
| Second-read moment | 의뢰 섹션의 거대한 숫자 `0.20`(층 높이 mm)을 구조 요소로 1회 |

- 방어 한 줄: 강조색은 실전코딩 캐릭터의 노란 후드에서 왔다. 바탕이 회색이 아닌 유채색 울트라마린이고 강조가 레몬 쪽 노랑이라 금지 조합(흑회색 + 주황·호박색, 흑색 + 네온)과 다르다. 노즐 끝 열기·터미널 블록 커서와도 같은 색이다.
- 포털 화면은 어두운 테마 하나. 글 읽기 페이지는 시스템 설정을 따르는 밝은/어두운 두 테마(같은 토큰에서 파생).
- 순수 검정(#000) 금지, 네온 글로우 금지, 그라데이션 덩어리 금지.

### Journey (single-shot, 약 15초 한 컷 — 홈 히어로 V1)
| 챕터 | 영상 속 순간 | 제목 | 한 문장 |
|---|---|---|---|
| 1 | 어둠 속 빈 빌드판, 뜨거운 노즐이 첫 층을 그린다(시작 상태) | 한 층씩 쌓는다. | 실전코딩 작업실에 온 걸 환영해요. |
| 2 | 노란 후드를 입은 캐릭터 피규어가 아래부터 층층이 올라온다 | 만들고, | 3D 프린터로 직접 만든 것들. |
| 3 | 피규어가 거의 완성, 노즐이 위로 빠진다 | 코딩하고, | 실무에서 배운 개발 이야기. |
| 4 | 카메라가 천천히 물러나며 어두운 작업실(모니터 빛 가장자리, 게임패드)이 살짝 보인다. 완성된 피규어가 중앙(끝 상태) | 플레이한다. | 게임 공략과 일상까지. |

- World grammar(모든 영상 프롬프트 앞에 그대로): cinematic macro product film, dark ultramarine-ink studio background (#0C1130), soft cool rim light, one warm practical light from the hot nozzle, shallow depth of field, 50mm lens, locked exposure and white balance, centered subject, slow continuous camera move, no cuts, no text, no logos.
- 카메라: 천천히 위로 오르며 뒤로 빠지는 한 번의 연속 이동. 끊김·흔들림·빠른 팬 없음.
- 모바일: 피사체를 화면 중앙 안전 영역에 둔다. 모바일은 720p 인코딩.
- 비용 구조: 스토리보드 이미지 1장(이번 단계) + 영상 1편(S5에서 비용 보고 후).
- 전송 예산: V1 데스크톱 ≤20 MiB·모바일 ≤8 MiB, 반복 영상 합계 데스크톱 ≤12 MiB·모바일 ≤6 MiB.
- 피규어 형태가 AI로 캐릭터와 다르게 나오면 블렌더 "층 차오름" 렌더로 대체·합성한다.
